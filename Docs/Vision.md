# Vision

## Nome do Projeto

Lessie Clone

## Missão

Criar uma plataforma de prospecção inteligente baseada em MCPs especializados capazes de localizar, enriquecer, organizar e priorizar oportunidades, empresas e pessoas.

## Problema

Profissionais e empresas perdem tempo navegando por múltiplas fontes de informação para encontrar oportunidades relevantes.

As informações estão dispersas, incompletas e exigem pesquisa manual.

## Solução

Uma plataforma capaz de orquestrar múltiplos MCPs especializados para:

* Encontrar pessoas.
* Encontrar empresas.
* Encontrar oportunidades.
* Enriquecer informações.
* Consolidar resultados.
* Utilizar IA para priorização e análise.

## Público-Alvo

* Desenvolvedores
* Consultores
* Recrutadores
* Empresas
* Profissionais em busca de oportunidades

## Objetivos

1. Demonstrar arquitetura moderna baseada em MCP.
2. Servir como showcase de AWS e IA.
3. Automatizar prospecção profissional.
4. Evoluir para produto comercial.

## Não Objetivos da V1

* CRM completo.
* ERP.
* Marketplace.
* Rede social.
* Multi-tenant corporativo.
* Sistema avançado de permissões.

## Diferencial

O sistema não depende de uma única integração.

Novos MCPs podem ser adicionados sem alterar a lógica principal da aplicação.

O produto é a orquestração dos MCPs.

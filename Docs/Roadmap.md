# Roadmap

## V1 - Foundation

Objetivo:

Criar a fundação técnica do produto.

Entregas:

* Google Login
* JWT
* Refresh Token
* Angular Shell
* Dashboard Inicial
* SQL Server
* Estrutura MCP Foundation

---

## V2 - MCP Foundation

Objetivo:

Criar a infraestrutura necessária para suportar MCPs.

Entregas:

* MCP Registry
* MCP Runner
* MCP Permissions
* MCP Configuration
* MCP Logging
* MCP Health Check

---

## V3 - People Discovery MCP

Objetivo:

Localizar pessoas relevantes.

Capacidades:

* Busca de profissionais
* Busca de recrutadores
* Busca por empresa
* Busca por cargo

---

## V4 - Company Discovery MCP

Objetivo:

Localizar empresas.

Capacidades:

* Busca por segmento
* Busca por localização
* Busca por tecnologia
* Busca por porte

---

## V5 - Opportunity Discovery MCP

Objetivo:

Localizar oportunidades.

Capacidades:

* Vagas
* Projetos
* Contratações
* Oportunidades compatíveis

---

## V6 - Lead Enrichment MCP

Objetivo:

Enriquecer dados coletados.

Capacidades:

* Consolidação de fontes
* Classificação
* Priorização
* Resumo por IA

---

## V7 - AI Orchestration

Objetivo:

Permitir que IA coordene múltiplos MCPs.

Exemplo:

Usuário solicita uma oportunidade.

IA decide:

1. Quais MCPs executar.
2. Em qual ordem executar.
3. Como consolidar os resultados.
4. Como apresentar a resposta.

---

## V8 - AWS Production

Objetivo:

Preparar ambiente produtivo.

Entregas:

* Docker
* Observabilidade
* Monitoramento
* Deploy AWS
* Escalabilidade
